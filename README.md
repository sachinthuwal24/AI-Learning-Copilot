# 🚀 AI Learning Copilot

AI-powered learning platform built using Python, Streamlit, Gemini API, SQLite, and YouTube API.

## Features

* 🗺️ AI Roadmap Generator
* 🤖 AI Mentor Chatbot
* 📝 Quiz Generator
* 🎥 Learning Resource Recommendations
* 📊 Learning Dashboard
* 🧠 Topic Recommendation Engine
* 💾 Progress Tracking

## Tech Stack

* Python
* Streamlit
* Gemini API
* SQLite
* Pandas
* NumPy
* Matplotlib
* YouTube Data API
